# big-event
# 大事件管理系统（Big Event）

一个基于 Spring Boot 和 Vue 开发的前后端分离的文章管理系统，主要实现用户认证、个人信息管理、文章分类管理和文章管理等功能。

本项目用于 Java 后端开发学习与实践，涉及 RESTful API、JWT 身份认证、MyBatis 数据访问、MySQL 数据库操作以及 Vue 前端开发。

## 一、项目介绍

本项目采用前后端分离架构：

* **后端**：负责业务逻辑处理、数据库交互、用户身份认证及接口数据返回。
* **前端**：负责页面展示、用户交互、发送 HTTP 请求及处理后端响应。
* **数据库**：使用 MySQL 存储用户、文章分类和文章等数据。

项目在基础文章管理功能之上，逐步完善认证、数据校验和前后端交互，为后续开发 AI 智能知识库项目打下基础。

## 六、后端运行

### 1. 创建数据库

在 MySQL 中创建项目数据库，并根据实际使用的 SQL 脚本创建相关数据表。

数据库名称：

```sql
CREATE DATABASE big_event;
```

如果数据库已存在，无需重复创建。

### 2. 配置数据库连接

根据本地环境修改后端配置文件，填写正确的数据库地址、用户名和密码。

同时检查 Redis 连接配置（如果启用了相关功能）。

**注意：不要将真实数据库密码、访问令牌或其他敏感信息提交到公开仓库。**

### 3. 启动后端

在项目根目录执行：

```bash
mvn spring-boot:run
```

如果本地 Maven Wrapper 已配置，也可以根据项目实际情况使用 Wrapper 启动。

后端默认端口以配置文件为准，当前项目通常使用：

```text
http://localhost:8080
```

## 七、前端运行

### 1. 进入前端目录

```bash
cd frontend
```

### 2. 安装依赖

```bash
npm install
```

### 3. 启动开发服务器

```bash
npm run dev
```

启动成功后，终端会显示本地访问地址，通常为：

```text
http://localhost:5173
```

请以终端实际输出为准。

### 4. 前后端联调

前端通过 Axios 发送 HTTP 请求，Vite 开发服务器根据 `vite.config.js` 中的代理配置，将 `/api` 请求转发到后端。

开发时需要确保：

1. MySQL 已启动。
2. Redis 已启动（如果项目需要）。
3. 后端已成功启动。
4. 前端开发服务器已启动。
5. 前端代理地址与后端端口一致。
